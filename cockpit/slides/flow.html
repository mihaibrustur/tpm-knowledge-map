Salesforce

02

Jira

The case becomes a Jira ticket, and the team channel gets an alert.

03

Triaged

Jira

Engineering confirms it: a bug, a configuration issue or a request.

04

Built

Jira

Code host

A small pull request, linked to the ticket, is reviewed and merged.

05

Released

CI

Slack

The fix ships, and the channel gets a short release note.

06

Closed

Slack

Salesforce

The case is updated, and support tells the customer.

Back to Salesforce: the case updates itself when the fix ships

The number that matters to customers: time from report to “it’s fixed”. The cockpit splits it into waiting and working time at every step, so you see where it really goes.

Walk through one real recent case if you have one. The point is that every step already leaves a trace in a tool; nobody has joined the traces up. Planned roadmap work follows the same path from step 3 onwards.
